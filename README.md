# BYU-Pathway Worldwide Online

## WDD 330 - Web Frontend Development II

### SleepOutside

SleepOutside is a multi-page outdoor gear storefront used for WDD 330 coursework.

## Setup

- Install dependencies with `npm install`.
- Start the Vite development server with `npm run start`.
- Run `npm run lint` to check JavaScript with ESLint.
- Run `npm test` to run the automated tests.
- Run `npm run build` to create the production build.

The application uses the WDD 330 backend for product data. Cart contents and product comments are stored in the current browser's localStorage.
